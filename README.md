# AI Clip Studio v0.2 — Android / игровые хайлайты

Локальный прототип Android-приложения, которое выбирает короткие фрагменты из записей игр и стримов для YouTube Shorts и Instagram Reels.

## Что работает в исходном коде

- Выбор исходного видео с телефона (Android OpenDocument).
- Алгоритм анализа пиков громкости и смен видеокадров.
- Интеграция **настоящей ИИ-модели YAMNet** (MediaPipe Audio Classifier) для распознавания звуковых событий — выстрелов, взрывов, смеха и криков.
- Ранжирование и выбор до пяти клипов, предпросмотр и правка границ.
- Вертикальный экспорт MP4, 720×1280 или 1080×1920, кадрирование либо сохранение всего кадра с полями.
- Сохранение в Movies / AI Clip Studio.

**Ограничения:** YAMNet распознаёт звуки, а не победы или убийства на изображении. Автоматические субтитры, распознавание игровых событий по картинке и точное отслеживание игрового персонажа ещё отсутствуют. Долгие ролики сканируются только на протяжении первых двух часов. Скорость анализа зависит от телефона.

## APK через GitHub Actions

1. Откройте вкладку **Actions** этого репозитория.
2. Выберите **Android APK**, затем успешно завершившийся запуск или **Run workflow**.
3. Скачайте **Artifacts → AIClipStudio-debug-apk**.
4. Распакуйте архив и установите **app-debug.apk** на Android 10+ (API 29).

Важно: APK публикуется только если компиляция завершилась успешно. Проверяйте статус запуска в Actions.

## ИИ-модель

При сборке выполняется загрузка `yamnet.tflite` из репозитория `litert-community/MediaPipe-AudioClassifier-YAMNet` на Hugging Face с проверкой SHA-256. Модель включается в APK. После установки для локального анализа сеть не нужна. Исходные видео не загружаются на сервер.

## Технологии

Kotlin, Android MediaCodec, Android MediaMetadataRetriever, Media3 ExoPlayer + Transformer, MediaPipe Tasks Audio / YAMNet. JDK 17, Android SDK 36, Gradle 8.13.

Это ранняя тестовая версия. Совместимость кодеков и синхронизацию экспорта необходимо проверять на реальных игровых записях.
